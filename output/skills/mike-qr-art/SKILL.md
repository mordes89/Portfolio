# Mike's portfolio QR artwork

Use this recipe when Mike requests another QR business-card design. Read [the winning recipe](references/winning-recipe.md) for exact settings and assets. This skill is saved with the portfolio project; global installation has not been verified.

Read [current addresses](references/current-addresses.md) before creating any QR; the original recipe contains the historical address.

## Preferences

- Prefer realistic New York buildings arranged along a coherent evening skyline, illuminated windows, water reflections, and subtle futuristic flowing light trails.
- Use New York Knicks blue and vivid orange, with orange expressed as a sunset glow. Earlier purple experiments were superseded; avoid pink and purple unless newly requested.
- Avoid toy-like buildings, mosaics of repeated towers, abstract circuit boards, and an ordinary QR pasted over an unrelated picture.
- Center Mike's actual LinkedIn/portfolio portrait in a small circle. Keep the original skyline QR separately.
- A working scan takes priority over artistic blending. Save versions Mike likes; do not overwrite a confirmed working original.
- Mike prefers a thin unobtrusive surrounding border, but retain enough separation for scanning. Border changes need another scan check.

## Workflow

1. Use the Hugging Face QR Code AI Art Generator named in the recipe when available. Enter the direct portfolio URL, not a subscription redirect. Do not enable paid usage or upgrades without approval. Stop on a quota limit and report it.
2. Start with the winning prompt, seed, and settings. Reproduction can vary with hosted model/software changes; reuse the saved PNG for an exact copy.
3. Make small parameter adjustments. Stronger ControlNet guidance often improves QR structure but can make the scene blockier. Preserve the preferred seed when tuning a design Mike likes.
4. Show the result in a persistent browser tab if remote image embeds fail. Mark the requested preview as a deliverable and reuse it. Export the result through supported browser asset/download tools before temporary URLs expire.
5. Verify that the unmodified artwork opens the exact portfolio URL, using a decoder if available and a phone scan. Then add the small real portrait and scan-check again. Record user-reported scans as such, not as independently automated verification.
6. For the approved portrait layout, use the existing SVG as a composition template: preserve the background pixels and replace only the embedded background image if necessary. Scale the face circle proportionally. Do not regenerate the face or the QR pattern for an overlay change.
7. Only publish a design to the portfolio when requested. A QR image does not require a paid service to remain usable; its destination must remain live.

If an approval prompt blocks progress, tell Mike promptly what action is waiting and why.
